## 📌 Sobre o Projeto

Este projeto consiste em um portfólio web pessoal, desenvolvido com o objetivo de centralizar minhas experiências, conhecimentos e projetos em um único ambiente digital.

A aplicação apresenta uma interface moderna, responsiva e intuitiva, permitindo que visitantes conheçam meu perfil profissional, acompanhem meus trabalhos e entrem em contato.

O desenvolvimento prioriza organização, usabilidade, identidade visual e compatibilidade com diferentes dispositivos.

## 🚀 Funcionalidades

- **Página Inicial:** apresentação pessoal e introdução ao perfil profissional.
- **Sobre Mim:** informações acadêmicas, trajetória profissional e conhecimentos técnicos.
- **Projetos:** apresentação de sistemas, aplicações e trabalhos desenvolvidos.
- **Serviços:** demonstração de soluções e atividades relacionadas à tecnologia.
- **Contato:** canais de comunicação e formulário para contato.
- **Responsividade:** adaptação da interface para computadores, tablets e smartphones.
- **Interatividade:** recursos dinâmicos e validações utilizando JavaScript.

## 💻 Como Executar o Projeto

Para visualizar o projeto localmente:

1. Faça o clone do repositório:

```bash
git clone https://github.com/gustavoteixeirasilva/Portfolio-Gustavo.git
```

2. Acesse a pasta:

```bash
cd Portfolio-Gustavo
```

3. Abra o arquivo `index.html` no navegador.

Não é necessário instalar dependências ou configurar um servidor para visualizar a versão estática.
