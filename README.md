# Portfólio Web — Gustavo Teixeira

Código-fonte do portfólio profissional desenvolvido para apresentar projetos, competências técnicas, serviços e canais de contato.

🔗 **Deploy:** [gustavoteixeirasilva.github.io/Portfolio-Gustavo](https://gustavoteixeirasilva.github.io/Portfolio-Gustavo/)

---

## Visão Geral

Aplicação web estática e responsiva construída com foco em performance, organização de código e navegação intuitiva entre seções.

### Páginas e Funcionalidades
* **`index.html`** — Página principal com resumo profissional e navegação.
* **`sobre.html`** — Trajetória acadêmica, experiência e stack de atuação.
* **`projetos.html`** — Catálogo de sistemas e aplicações desenvolvidas.
* **`serviços.html`** — Detalhamento de soluções em desenvolvimento e tecnologia.
* **`contato.html`** — Formulário e links diretos para contato profissional.
* **`script.js`** — Manipulação do DOM, interatividade de interface e validações.
