## 💻 Sobre o Projeto

Este repositório contém o código-fonte do meu portfólio pessoal como **Desenvolvedor Full Stack**. O objetivo do projeto é centralizar minha trajetória, demonstrar minhas principais aplicações desenvolvidas e facilitar a conexão com recrutadores, clientes e outros desenvolvedores.

### ✨ Funcionalidades e Páginas
- **Início (`index.html`):** Apresentação pessoal, resumo profissional e destaques.
- **Sobre (`sobre.html`):** Minha jornada na tecnologia, formação e foco de atuação.
- **Projetos (`projetos.html`):** Vitrine interativa com os principais sistemas e aplicações desenvolvidas.
- **Serviços (`serviços.html`):** Soluções oferecidas em desenvolvimento web, APIs e suporte/infraestrutura.
- **Contato (`contato.html`):** Canais diretos e formulário para orçamento, networking ou oportunidades.

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias web fundamentais para garantir carregamento rápido, responsividade e compatibilidade:

  <img src="https://skillicons.dev/icons?i=html,css,js,git,github,vscode" alt="Tecnologias do Portfólio" />

- **HTML5:** Estruturação semântica das páginas e SEO.
- **CSS3:** Estilização moderna, layout responsivo (Mobile First) e animações.
- **JavaScript (ES6+):** Interatividade, manipulação do DOM e validações dinâmicas.
- **GitHub Pages:** Hospedagem e deploy contínuo.
